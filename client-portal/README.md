# Client Portal

The Beyond Finance client portal is the primary web application for enrolled clients to view their debt resolution progress, approve settlement agreements, and manage their account. Built on Ruby on Rails 7.x with PostgreSQL, it integrates with Salesforce via the Glue API.

**Tech Stack:** Rails 7, PostgreSQL 14, Redis, Sidekiq, Tailwind CSS

**Local Setup:** `bundle install && rails db:setup && rails s`
